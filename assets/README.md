# Assets

Icons and data used by the profile README and the `readme-updater` package.

- `git-pull-request.svg`, `issue-opened.svg`, `git-commit.svg`, `mark-github.svg`: [Primer Octicons](https://github.com/primer/octicons), MIT licensed (see [LICENSE-octicons](LICENSE-octicons)), tinted `#8b949e` so they stay visible on the light and the dark theme.
- `python.svg`, `typescript.svg`: [Devicon](https://github.com/devicons/devicon), MIT licensed (see [LICENSE-devicon](LICENSE-devicon)), in their original brand colors.
- `rust.svg`: [Simple Icons](https://github.com/simple-icons/simple-icons), CC0. Rust's mark is monochrome, so it is tinted `#dea584` (GitHub's language color for Rust) to stay visible on both themes.
- `csshw-logo.svg`: copied from [whme/csshw](https://github.com/whme/csshw), my own project.
- `language-colors.json`: the language → color map from [github-linguist](https://github.com/github-linguist/linguist), MIT licensed. Used to color the language bars.
- `languages.svg`, `languages-recent.svg`, `languages-cache.json`: generated by `readme-updater`; do not edit by hand.

## How the language bars are computed

Both bars measure the **lines I added** per language — all-time and over
the last 30 days — across every repository I commit to, private ones
included. A file's language comes from its extension; generated and
vendored files are skipped.

`languages-cache.json` is what keeps this cheap. It records, per
repository, the newest commit already counted, plus the running all-time
totals and per-day buckets for the recent window. Each run only fetches
the commits added since last time (via the list-commits API, which
reaches private and huge repositories alike), so the first run does the
whole history and every run after it does almost nothing.

## How the language block copes with change

The distribution is regenerated on every run, so the set of languages
it names can grow over time. Two mechanisms keep that from needing new
assets:

- **Colors** come from `language-colors.json`, which covers every
  language GitHub knows, so a newly-appearing language always gets its
  proper color; only truly unknown ones fall back to gray.
- **Icons** are curated for the few languages worth an icon
  (`LANGUAGE_ICONS` in the package). Any language without one simply
  renders as text in the legend — no missing image, nothing to add.
